Validador de E-mail com Node.js e Jest

Este é um projeto simples de aprendizado para validação de formatos de e-mail utilizando **Node.js** e testes automatizados com **Jest**.

### Como começar

### Pré-requisitos
    Certifique-se de ter o [Node.js](https://nodejs.org/) instalado na sua máquina.

### Instalação
1. Clone este repositório:

   git clone https://github.com/2510879-Adilson/validar_email_node.git

2. Entre na pasta do projeto:

   cd validar_email_node

3. Instale as dependências:

    npm install

   
### Como rodar os testes

Para verificar se a função de validação está funcionando corretamente, execute:

npm test
